# CHANGE LOG — randui-standardization-v1

## Changes
- Added DTCG-compatible portable RandUI tokens.
- Added independently versioned motion contract with reduced-motion fail-safe.
- Added semantic icon adapter policy with MingCute as approved migration target.
- Preserved `RANDUI_VERSION=1.0.0` after CI exposed the risk of coupling standardization version to rebuild version.
- Added standardization tests and architecture documentation.
- Preserved Ocean/CI preview artifacts because they remain live references and are not zombies.
