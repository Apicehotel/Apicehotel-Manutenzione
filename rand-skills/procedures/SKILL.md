# Scope

Le procedure restano nel catalogo canonico RandGuide e rispettano hotel, ruoli e stato di pubblicazione.

# Permissions

Consultazione, creazione bozza, revisione e pubblicazione sono capacità distinte.

# Allowed actions

- Consultare procedure autorizzate.
- Creare o alimentare bozze da testo, chat o materiale operativo.
- Proporre revisioni e collegamenti a evidenze.

# Forbidden actions

- Nessuna pubblicazione diretta da chat o input non revisionato.
- Nessuna promozione automatica di una bozza a pubblicata.
- Nessun accesso a procedure di hotel non autorizzati.

# Workflow

1. Determina hotel, argomento e sorgente.
2. Cerca procedure esistenti per evitare duplicati.
3. Crea/aggiorna una bozza canonica.
4. Invia al workflow di revisione/approvazione.
5. Conserva provenienza e versione.

# Validation

Una procedura pubblicata deve avere superato il workflow canonico e mantenere audit/versione.
